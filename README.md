## Publish the website

The complete, approved site package was prepared as `HEADMOSH_ATLAS_PUBLIC_TEST_134.zip`.

1. Download and **extract** that ZIP locally.
2. Open **GitHub Desktop**, clone this repository, and open its folder.
3. Copy the extracted **`index.html`, `catalog.json`, and entire `assets/` folder** into the repository folder (replace this README if desired).
4. In GitHub Desktop, commit the files to `main` and **Push origin**.
5. In GitHub, open **Settings → Pages**. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
6. The live preview will be at `https://hand3seen.github.io/headmosh-atlas-preview/` after deployment.

### Safety
Only the reviewed public image set belongs here. Do not upload review decisions JSON, original archive ZIPs, family photos marked private, student media without rights clearance, or unreviewed files. The public site package uses neutral filenames and metadata-stripped images.
